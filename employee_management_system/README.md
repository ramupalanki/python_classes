# Employee Management System

A simple Python project demonstrating Object-Oriented Programming (OOP) through an Employee Management System.

## Features

The `Employee` class contains:

- Employee ID
- Name
- Department
- Salary
- Designation

The class provides the following methods:

- `display_employee_info()` - Displays employee details.
- `update_salary()` - Updates the employee's monthly salary.
- `calculate_annual_salary()` - Calculates annual salary using monthly salary × 12.

## OOP Concepts Demonstrated

### 1. Class
`Employee` is the class that defines the structure and behavior of an employee.

### 2. Objects
Five employee objects are created from the `Employee` class.

### 3. Constructor
The `__init__()` method initializes employee data when an object is created.

### 4. Instance Attributes
Each employee object has its own:

- `employee_id`
- `name`
- `department`
- `salary`
- `designation`

### 5. Instance Methods
The class contains methods that operate on individual employee objects.

Make sure Python is installed.

Run:

```bash
python employee_management.py
```

## Expected Output

The program displays:

1. Details of all five employees.
2. Annual salary for each employee.
3. A salary update for one employee.
4. The updated annual salary.
5. A final employee summary.
